# אתר האמן טל לוי

אתר של עמוד אחד (`index.html`), בלי שלב בנייה. פותחים את הקובץ בדפדפן וזה עובד.

## הוספת ציורים
1. שמים את צילומי הציורים בתיקייה `images/` (למשל `01.jpg`, `02.jpg`). מומלץ צילום ישר, באור יום, ברוחב של עד 2000px.
2. ב-`index.html`, ברשימה `PAINTINGS`, ממלאים לכל ציור: `image: "images/01.jpg"`, שם, שנה, מידות, טכניקה, סגנון ומחיר.
3. מוסיפים או מוחקים שורות לפי מספר הציורים. כשציור נמכר: `sold: true`.

## פרטי קשר
ב-`CONFIG` בראש הסקריפט: מייל, מספר וואטסאפ (פורמט 9725XXXXXXXX) ואינסטגרם.
טופס הרכישה פותח הודעה מוכנה בוואטסאפ או במייל, ולא צריך שרת.

## העלאה לאוויר
`vercel deploy --prod --yes` מתוך התיקייה הזאת. כל העלאה מחליפה את הגרסה הקודמת.
