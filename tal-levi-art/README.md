# אתר האמן טל לוי

אתר של עמוד אחד (`index.html`), בלי שלב בנייה. פותחים את הקובץ בדפדפן וזה עובד.

## הציורים
- 38 עבודות מתיקיית ה-Drive. לכל עבודה צילום מלא (`images/wNN.jpg`), צילומי תקריב (`wNN-d1.jpg`...) ותמונה מוקטנת לגלריה (`images/thumbs/`).
- `images/manifest.json` מראה מאיזה קובץ מקורי (`tal.levi N.jpg`) הגיעה כל תמונה. המקוריים שמורים ב-`../photos-original/`.
- את הפרטים ממלאים ב-`index.html`, ברשימה `PAINTINGS`: שם, שנה, מידות, טכניקה, סגנון ומחיר. שדה ריק פשוט לא מוצג. כשציור נמכר: `sold: true`.
- השיוך לסגנונות (אבסטרקט / סוריאליזם / אקספרסיוניזם) הוא ניחוש ראשוני, וטל צריך לעבור עליו.

## פרטי קשר
ב-`CONFIG` בראש הסקריפט: מייל, מספר וואטסאפ (פורמט 9725XXXXXXXX) ואינסטגרם.
טופס הרכישה פותח הודעה מוכנה בוואטסאפ או במייל, ולא צריך שרת.

## העלאה לאוויר
`vercel deploy --prod --yes` מתוך התיקייה הזאת. כל העלאה מחליפה את הגרסה הקודמת.
